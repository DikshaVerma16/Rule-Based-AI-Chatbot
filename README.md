# Rule-Based AI Chatbot 🤖

## Project Overview
This project was developed as part of the DecodeLabs Artificial Intelligence Internship.

The chatbot is built using Python and responds to predefined user inputs using if-elif-else statements. It runs continuously until the user enters "bye" or "exit".

## Features
- Greeting responses
- Answers basic AI-related questions
- Displays current date and time
- Handles unknown inputs
- Continuous conversation loop
- Exit command support

## Technologies Used
- Python
- Google Colab
- GitHub

## How to Run
1. Open the notebook in Google Colab or Jupyter Notebook.
2. Run the code cell.
3. Start chatting with the bot.
4. Type `bye` or `exit` to stop the chatbot.
